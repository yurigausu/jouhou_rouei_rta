# 情報漏えいRTA 〜とある新入社員の5日間〜

架空の会社を舞台に、情報漏えいと SNS 炎上を題材にした見下ろし型の風刺ステルスゲームです。ブラウザで動きます(プロトタイプ v0.5)。

> [!WARNING]
> **フィクションの風刺ゲームです。実在の企業・事件とは関係ありません。現実で同じことをすると懲戒解雇・損害賠償・刑事責任につながります。**

## 遊び方

### コンセプト

プレイヤーは入社したばかりの新入社員です。社内の資料をこっそり撮影して SNS に投稿し、5日間でどれだけ会社を炎上させられるかを競います。

### 5日間の流れ

1. 1日は40秒です。同僚の視線を避けながら資料に近づき、長押しで撮影します。撮影が終わると自動で投稿され、その場ではいいね数だけが表示されます。
2. 資料には撮影できる時間帯があります。問題度(★)が高い資料ほど、撮影に時間がかかります。
3. 時間切れか「退勤」ボタンで1日が終わり、翌日へ進みます。
4. 5日目が終わると「後日ニュース」の画面になり、全投稿の炎上スコアとランクがまとめて判明します。

### 警戒度と解雇

- 同僚の視線の中で撮影するか、立入エリア(会議室・資料室・役員室)にいるところを見られると、警戒度が上がります。
- 撮影のシャッター音が聞こえた近くの同僚は振り向きます。そのまま視線に入ると、警戒度がさらに上がります。同僚は巡回の途中で不意に振り向くこともあります。
- 自分のデスク(★)で仕事をすると警戒度が下がります。一晩経っても少し下がります。
- 警戒度が最大になると即日解雇となり、ゲームオーバーです。それまでの投稿は評価されません。

### 入れる部屋

日が進むと入れる部屋が増え、問題度の高い資料に触れられるようになります。

| 日 | 新しく入れる部屋 |
|----|------------------|
| 1日目 | 執務エリア、研修室 |
| 2日目 | 会議室 |
| 3日目 | 資料室 |
| 4日目 | 役員室 |

### スコアの考え方

- 早い日の投稿ほど拡散する時間が長く、倍率が高くなります。ただし、序盤に撮れるのは問題度の低い資料だけです。
- 終盤は問題度の高い資料を撮れますが、倍率は下がります。どの日に何を撮るかの配分がポイントです。
- 同じ資料を再投稿しても、ほとんど伸びません。
- 最終日の終了時に警戒度が残っていると、合計スコアから減点されます。

## 操作方法

## 技術メモ

- **構成**: Vanilla JS と Canvas 2D による単一 HTML ファイル(`index.html`)。CSS と JavaScript もすべてこのファイルに含まれます。
- **外部依存**: 外部ライブラリなし。外部から読み込むのは Google Fonts(DotGothic16)のみです。
- **視線コーン**: 判定は距離、角度、遮蔽物の順に確認します。描画はレイを扇状に飛ばし、壁と未解放のドアで切り取っています。
- **同僚の動き**: 巡回ルートに沿って移動し、ランダムなタイミングで振り向きます。シャッター音にも反応します。
- **撮影対象**: 出現する日と、1日の中で撮影できる時間窓を対象ごとに持たせています。出現前はカウントダウン付きで薄く表示し、消える直前は色を変えて残り秒数を表示します。
- **日英切り替え**: 文言を言語別の辞書にまとめ、選んだ言語は `localStorage` に保存します。
- **タッチ操作**: Pointer Events で仮想スティックと長押しボタンを実装しています。
- **画面**: 960×640 の固定座標で処理し、ウィンドウサイズに合わせて拡大縮小します。

## English summary

**Info Leak RTA — 5 Days of a New Hire** is a top-down satirical stealth game that runs in the browser. You play a new hire at a fictional company, secretly photographing documents and posting them to social media while avoiding your coworkers' lines of sight. Your posts are only scored after the five days end.

This is fiction and has no connection to any real company or incident. Doing this in real life can lead to dismissal, damage claims and criminal liability.

It is a single HTML file written in vanilla JS and Canvas, with an in-game Japanese/English switch. The code was written by AI (Claude), while a human handled the concept, review, device testing and balancing. Sound effects are not included because their license prohibits redistribution; the game works without them.
